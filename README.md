# SpoofCard Growth Audit

**Live → https://eddieatadapty.github.io/spoofcard-flow-rebuild/**

Five ideas to turn more SpoofCard users into subscribers, each built into a clickable version of SpoofCard's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Set up the first call or text before any price | +10–20% CR to first purchase |
| 02 | Keep each ad’s promise on the first screen | +5–10% CR to first purchase |
| 03 | Let one answer pick the number and the headline | +5–10% CR to first purchase |
| 04 | Spell out the first-purchase bonus and the price per credit | +5–15% ARPU |
| 05 | Offer the smaller first pack once, on close | +3–8% CR to first purchase |

Every price, rating and feature comes from SpoofCard's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ apps, not measured lift for SpoofCard. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
